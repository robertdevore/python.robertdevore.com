		<h1>1.2. Syntax & Data Types</h1>
		<p class="docs-description">Master Python's basic building blocks—variables, data types, and simple operations—so you can start manipulating data with confidence.</p>
		<div class="docs-meta" aria-label="Page metadata"><span class="docs-badge docs-badge-section"><span>Section</span>Chapter 1 · Beginner Python</span><span class="docs-badge docs-badge-audience"><span>Audience</span>Python learners</span><span class="docs-badge docs-badge-difficulty"><span>Difficulty</span>beginner</span><span class="docs-badge docs-badge-status"><span>Status</span>stable</span><span class="docs-badge docs-badge-version"><span>Version</span>complete course</span><span class="docs-badge docs-badge-updated"><span>Updated</span>2025-06-17</span></div>

		<div class="docs-body"><h2>Overview</h2>
<p>Master Python&apos;s basic building blocks—variables, data types, and simple operations—so you can start manipulating data with confidence. Python&apos;s beauty lies in its simplicity and readability. In this section, you&apos;ll learn how Python represents information, how to give that information useful names, and how to combine values into expressions.</p>
<p>By the end of this lesson, you will be able to:</p>
<ul>
<li>Read and write basic Python statements</li>
<li>Store values in clearly named variables</li>
<li>Work with strings, integers, floating-point numbers, booleans, and <code>None</code></li>
<li>Inspect and convert between common data types</li>
<li>Use arithmetic, comparison, and logical operators</li>
<li>Format readable output with f-strings</li>
</ul>
<h2>Python syntax at a glance</h2>
<p>Python uses whitespace and indentation to communicate structure. A simple statement usually occupies one line:</p>
<pre><code class="language-python">course_name = &quot;Complete Python Development Course&quot;
lesson_number = 2
print(course_name, lesson_number)</code></pre>
<p>Names are case-sensitive, so <code>lesson</code>, <code>Lesson</code>, and <code>LESSON</code> are three different variables. Choose descriptive lowercase names, separate words with underscores, and avoid Python keywords such as <code>class</code>, <code>for</code>, and <code>if</code>.</p>
<p>Comments begin with <code>#</code> and explain intent to future readers:</p>
<pre><code class="language-python"># Prices are stored in US dollars.
monthly_price = 19.99</code></pre>
<p>Good comments clarify why code exists. The code itself should make what it does easy to understand.</p>
<h2>Variables and assignment</h2>
<p>A variable is a name that points to a value. Python creates the name when you assign a value with <code>=</code>:</p>
<pre><code class="language-python">student_name = &quot;Avery&quot;
completed_lessons = 3
is_enrolled = True</code></pre>
<p>Python is dynamically typed. You do not declare a variable&apos;s type before using it; Python determines the type from the assigned value. You can inspect that type with <code>type()</code>:</p>
<pre><code class="language-python">print(type(student_name))       # &lt;class &apos;str&apos;&gt;
print(type(completed_lessons))  # &lt;class &apos;int&apos;&gt;
print(type(is_enrolled))        # &lt;class &apos;bool&apos;&gt;</code></pre>
<p>Reassignment gives an existing name a new value:</p>
<pre><code class="language-python">completed_lessons = 3
completed_lessons = completed_lessons + 1
completed_lessons += 1
print(completed_lessons)  # 5</code></pre>
<p>Constants are conventionally written in uppercase. Python does not prevent you from changing them, but the style signals that the value should remain stable:</p>
<pre><code class="language-python">LESSONS_PER_CHAPTER = 5</code></pre>
<h2>Core data types</h2>
<h3>Integers and floating-point numbers</h3>
<p>An <code>int</code> stores a whole number, while a <code>float</code> stores a number with a decimal component:</p>
<pre><code class="language-python">lesson_count = 20      # int
completion = 82.5     # float</code></pre>
<p>Python supports the arithmetic operators you would expect:</p>
<pre><code class="language-python">print(10 + 3)   # addition: 13
print(10 - 3)   # subtraction: 7
print(10 * 3)   # multiplication: 30
print(10 / 3)   # division: 3.333...
print(10 // 3)  # floor division: 3
print(10 % 3)   # remainder: 1
print(10 ** 3)  # exponent: 1000</code></pre>
<p>Parentheses make the intended order of operations explicit:</p>
<pre><code class="language-python">average = (88 + 91 + 95) / 3</code></pre>
<h3>Strings</h3>
<p>A <code>str</code> stores text. Use matching single or double quotes:</p>
<pre><code class="language-python">language = &quot;Python&quot;
message = &apos;Readable code matters.&apos;</code></pre>
<p>Strings can be combined, repeated, indexed, and sliced:</p>
<pre><code class="language-python">full_message = language + &quot;: &quot; + message
banner = &quot;=&quot; * 20
first_letter = language[0]     # P
short_name = language[:3]      # Pyt</code></pre>
<p>F-strings are the clearest way to insert values into text:</p>
<pre><code class="language-python">name = &quot;Avery&quot;
lessons = 4
print(f&quot;{name} has completed {lessons} lessons.&quot;)</code></pre>
<p>Useful string methods return transformed values:</p>
<pre><code class="language-python">raw_name = &quot;  robert devore  &quot;
clean_name = raw_name.strip().title()
print(clean_name)  # Robert Devore</code></pre>
<p>Strings are immutable, which means their individual characters cannot be changed in place. Methods such as <code>.strip()</code> and <code>.title()</code> create new strings.</p>
<h3>Booleans</h3>
<p>A <code>bool</code> is either <code>True</code> or <code>False</code>. Booleans often come from comparisons:</p>
<pre><code class="language-python">score = 92
passed = score &gt;= 70
perfect = score == 100
print(passed)   # True
print(perfect)  # False</code></pre>
<p>Comparison operators include <code>==</code>, <code>!=</code>, <code>&lt;</code>, <code>&lt;=</code>, <code>&gt;</code>, and <code>&gt;=</code>. Combine conditions with <code>and</code>, <code>or</code>, and <code>not</code>:</p>
<pre><code class="language-python">has_account = True
email_verified = False
can_continue = has_account and email_verified
needs_verification = has_account and not email_verified</code></pre>
<h3>None</h3>
<p><code>None</code> represents the intentional absence of a value:</p>
<pre><code class="language-python">middle_name = None

if middle_name is None:
    print(&quot;No middle name provided&quot;)</code></pre>
<p>Use <code>is None</code> and <code>is not None</code> when checking for this special value.</p>
<h2>Type conversion</h2>
<p>Programs often receive values as strings, especially from <code>input()</code>. Convert them before doing numeric work:</p>
<pre><code class="language-python">age_text = &quot;34&quot;
age = int(age_text)
next_year = age + 1
print(next_year)  # 35</code></pre>
<p>Common conversion functions include <code>int()</code>, <code>float()</code>, <code>str()</code>, and <code>bool()</code>:</p>
<pre><code class="language-python">quantity = int(&quot;5&quot;)
price = float(&quot;12.50&quot;)
summary = str(quantity) + &quot; items&quot;</code></pre>
<p>Invalid conversions raise an error. For example, <code>int(&quot;five&quot;)</code> cannot produce a number. Later lessons show how to handle that failure gracefully.</p>
<h2>Input and output</h2>
<p>The <code>input()</code> function pauses the program and returns what the user typed as a string:</p>
<pre><code class="language-python">name = input(&quot;What is your name? &quot;)
year_text = input(&quot;What year were you born? &quot;)
year = int(year_text)

print(f&quot;Welcome, {name}! You entered {year}.&quot;)</code></pre>
<p>Clear prompts and formatted output make even a small command-line program easier to use.</p>
<h2>A small practice program</h2>
<p>Combine variables, conversion, arithmetic, and f-strings in a simple bill calculator:</p>
<pre><code class="language-python">item_name = input(&quot;Item name: &quot;)
unit_price = float(input(&quot;Unit price: &quot;))
quantity = int(input(&quot;Quantity: &quot;))
tax_rate = 0.06

subtotal = unit_price * quantity
tax = subtotal * tax_rate
total = subtotal + tax

print(&quot;\nOrder summary&quot;)
print(&quot;-&quot; * 24)
print(f&quot;Item: {item_name}&quot;)
print(f&quot;Subtotal: ${subtotal:.2f}&quot;)
print(f&quot;Tax: ${tax:.2f}&quot;)
print(f&quot;Total: ${total:.2f}&quot;)</code></pre>
<p>The <code>:.2f</code> format specifier displays a floating-point number with two decimal places. Try changing the quantity, price, or tax rate and predict the result before you run the program.</p>
<h2>Common beginner mistakes</h2>
<ul>
<li>Using <code>=</code> when you mean <code>==</code>. Assignment stores a value; equality compares two values.</li>
<li>Mixing strings and numbers without conversion. <code>&quot;5&quot; + &quot;2&quot;</code> produces <code>&quot;52&quot;</code>, while <code>5 + 2</code> produces <code>7</code>.</li>
<li>Misspelling a variable name or changing its capitalization.</li>
<li>Forgetting that <code>input()</code> always returns a string.</li>
<li>Naming a variable <code>str</code>, <code>list</code>, or <code>type</code>, which hides a useful built-in name.</li>
<li>Assuming floating-point arithmetic is perfectly exact. Values such as <code>0.1 + 0.2</code> may contain tiny representation differences.</li>
</ul>
<h2>Practice exercises</h2>
<p>1. Create variables for your name, favorite number, and whether you have used Python before. Print one formatted sentence containing all three values.</p>
<p>2. Ask for a temperature in Celsius and convert it to Fahrenheit with <code>(celsius * 9 / 5) + 32</code>.</p>
<p>3. Ask for the width and height of a rectangle, then print its area and perimeter.</p>
<p>4. Store a sentence and print its length, uppercase form, and first ten characters.</p>
<p>5. Build a tip calculator that accepts a bill amount and percentage, then prints the tip and final total.</p>
<p>You now have the vocabulary every Python program depends on: names, values, types, expressions, input, and output. Next, you will use those values to make decisions and repeat work with conditionals and loops.</p></div>
